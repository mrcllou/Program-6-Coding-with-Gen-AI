## Reflection 
1. What did you learn in the process?
   During this process, I learned how to use Gen AI more carefully than I've been using it. It's not the first time that I have used AI for
   coding, but this process makes me realize that the AI ​​can be really vague and wander off course if you don't tell it what to do,
   one step at a time. This can be really annoying since the purpose of the assignment is to drive the AI ​​and really let the AI ​​do whatever it wants.
3. What were the benefits of working with GenAI?
   The biggest benefit of working with GenAI was the speed at which it could generate ideas, code, and solutions. It helped me
   brainstorm project features and create a foundation for my program much faster than if I had started from scratch. It was also
   useful for explaining concepts, suggesting improvements, and helping me organize my project structure.
5. What were the drawbacks?
   One drawback is that, as I said in "The prompt," if you don't have the premium version of Claude, your coding is limited, so you have to
   stop at some point. Another drawback is that we can rely too much on AI, so as an output make it easy to accept solutions without fully
   understanding them, which can be a problem when learning programming concepts.
7. Any other thoughts?
   This assignment is very interesting, since it's not common to make a student code with a new tool like AI, which is very cool.
   It also shows me that AI is a powerful tool, but it is most effective when used as a sort of third party than a replacement for human thinking.
